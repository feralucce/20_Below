Tools

20 Below Battle Tracker
Import PCs and NPCs, roll Initiative, declare Action Brackets with Ki bumps, and track Health, Poise, Sanity and Ki through the turn order. The same tracker runs as an Owlbear Rodeo extension and as a desktop app.
Encounter Difficulty Calculator
Load the party once, then build a fight and see what it costs before anyone sits down. Runs in a browser and as a desktop app.
The Brewery
Write in plain markdown and it lays the page out in the system's own typefaces and colours, then prints to PDF - two columns, sidebars, callout boxes, roll stamps, and a print mode with the gutters and bleed a print-on-demand service expects. The same tool the core book is made with, and it also runs as a desktop app.

Part of the 20 Below core rules. Source and full history at github.com/feralucce/20_Below.
