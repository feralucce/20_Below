Apps & Extensions

Downloads

Tools for running 20 Below - at the table, on a virtual tabletop, or on your own machine.

None of this is required to play — the rules are free and complete on their own. Everything below is free too, and nothing in your browser needs installing.

In your browser

Character Creator
Build a character step by step and export it as JSON. Nothing to install, and it always reads the current rules.
Battle Tracker
Run a fight in a browser tab: load your characters, roll Initiative, declare Action Brackets, and track Health, Poise, Sanity and Ki through the turn order. Works alongside any virtual tabletop, or none at all.
The Brewery
Write in markdown, get pages laid out to print. Two columns by default, with stat blocks, callouts and roll boxes, four trim sizes, and a Print/PDF button. Pick a theme to match the setting you're writing for.

Desktop

Character Creator Windows · v0.10.0
The whole character creator as a native app. Pulls the current rules whenever it can reach the internet, and falls back to the copy it shipped with when it can't.
Battle Tracker Windows · v0.2.0
Run a fight without a virtual tabletop: Initiative, Action Brackets, turn order, and Health, Poise, Sanity and Ki for everyone in the scene.
The Brewery Windows · v0.2.0
The layout tool as a native app, typefaces and all, so it works with no internet and prints the same on every machine. Themes for 20 Below Core and Backwater Static, with more arriving as each setting is released.

Owlbear Rodeo

In Owlbear Rodeo, open the extensions menu, choose to add a custom extension, and paste the URL below the description. They're free, and they read the same character JSON the creator exports.

20 Below Dice
The player-facing roller: core rolls, Advantage and Disadvantage, and damage pools, optionally tied to your own character.
https://feralucce.github.io/20_Below_Dice/manifest.json
20 Below Battle Tracker
The GM’s panel: every character in the session, plus the full Battle Tracker - Initiative, Action Brackets, turn order and damage. Drop a character onto the scene as a token in one click, or link one that is already there. Load art alongside a character file and it is used for both the token and the roster.
https://feralucce.github.io/20_Below_Roster/manifest.json

Roll20

Roll20 support Soon
No Roll20 plugin yet. Roll20's scripting runs on their server with no interface of its own, and it needs a Pro subscription — so in the meantime, the browser Battle Tracker above runs beside a Roll20 game and does the same job, free.

Backwater Static Assets

Maps, NPCs & Anomalies Soon
Table-ready material for Backwater Static - maps, NPC exports, Loose Anomalies, and the Anomalous Items Index. Free, like the setting itself.
