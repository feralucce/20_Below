About 20 Below

One line

20 Below is a fated-heroes tabletop roleplaying game that you can play in any world you bring to it. The rules, the first setting and every digital tool are free.

Short description

20 Below is a fated-heroes tabletop RPG: a 2d10 roll-under core, five elemental Attributes, and supernatural Gifts layered over whatever world you bring to it. The core rules are free forever under the ORC License, and so is its first full setting, Backwater Static, a supernatural New Orleans built on secrecy and static.

Long description

20 Below is a setting-agnostic tabletop roleplaying game about fated heroes. Its core is a 2d10 roll-under system built on five elemental Attributes, with supernatural Gifts that let each character bend the world in their own way. It’s designed so first-time players and longtime veterans can sit at the same table.

The core rules are free and stay free, released under the ORC License. No paywall, no rug pull.

Backwater Static, the first full setting, shows what the system can carry: a New Orleans built on secrecy and static, where something under the city has been awake for a while. It’s free too.

Alongside the rules, the team builds the tools to play them: a Character Creator for web, phone and desktop, a Battle Tracker, extensions for the Owlbear Rodeo virtual tabletop, an Encounter Difficulty Calculator, and the Brewery, a layout tool for homebrew. All free.

What’s Free Today

  • The core rules: complete, on the website.
  • Backwater Static: the full setting.
  • The Quick Reference Guide: every player reference sheet in one printable PDF.
  • Character Creator: runs in the browser, installs to a phone, and has a Windows app.
  • Battle Tracker: runs in the browser, with a Windows app.
  • Owlbear Rodeo extensions: a player character sheet and a GM battle panel for the virtual tabletop.
  • Encounter Difficulty Calculator: runs in the browser, with a Windows app.
  • The Brewery: write in markdown and get print-ready pages, with themes for 20 Below and Backwater Static.
  • Coming soon: Backwater Static maps, NPCs and Anomalies, also free.
