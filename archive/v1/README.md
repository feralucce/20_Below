# v1 — Archived 2026-07-16

This is the first full design pass at the system: a WoD-inspired point-buy build (Attributes/Skills/Perks/Gifts/Flaws), a Health Level wound track, Resonance as the universal resource, and a 55-Gift catalog that went through a full concrete-mechanics review.

**Superseded.** The user's goal was a simple, intuitive, fast-play RPG, and this design grew too complex chasing mechanical completeness (per-Gift Resonance costs, a Health Level container system, elemental sub-attribute mapping, escalating DoS formulas). Kept here for reference — reusable ideas, phrasing, and hard-won design decisions — not as the active ruleset.

Nothing here is deleted or wrong, it just isn't where the system is headed. See the top-level [README.md](../../README.md) for what's active now.
