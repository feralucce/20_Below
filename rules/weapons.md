# Weapons

Each weapon's rating is how many d10 it rolls on a hit, resolved per-die against the defender's Soak, as described in [rules.md](rules.md#physical-attacks--weapon-damage--per-die-resolution).

## Basic Weapons

Range is given as **Normal / Long**, in meters - the same unit as [Movement Rate](rules.md#movement--range). Long range's exact mechanical penalty (most likely Disadvantage) isn't defined yet.

| Weapon | Dice | Range (Normal / Long) | Ammo |
|---|---|---|---|
| Unarmed strike | 1d10 | Melee | - |
| Knife / small blade | 2d10 | Melee | - |
| Improvised (bat, pipe, chair) | 2d10 | Melee | - |
| Thrown weapon (knife, axe, javelin) | 2d10 | 5m / 15m | 1 per throw |
| Sword / axe (one-handed) | 3d10 | Melee | - |
| Machete / large blade | 3d10 | Melee | - |
| Bow / crossbow | 3d10 | 20m / 50m | 12 (quiver) |
| Polearm / two-handed blade | 4d10 | Melee | - |
| Handgun | 5d10 | 15m / 40m | 15 rounds |
| Submachine gun | 6d10 | 25m / 60m | 30 rounds |
| Rifle | 7d10 | 100m / 250m | 20 rounds |
| Shotgun (close range) | 8d10 | 5m / 15m | 6 shells |
| Heavy/anti-materiel weapon | 10d10 | 300m / 800m | 5 rounds |
