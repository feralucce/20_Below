# Weapons

Each weapon's rating is how many d10 it rolls on a hit, resolved per-die against the defender's Soak, as described in [core-mechanic.md](core-mechanic.md#physical-attacks--weapon-damage--per-die-resolution).

## Basic Weapons

| Weapon | Dice |
|---|---|
| Unarmed strike | 1d10 |
| Knife / small blade | 2d10 |
| Improvised (bat, pipe, chair) | 2d10 |
| Thrown weapon (knife, axe, javelin) | 2d10 |
| Sword / axe (one-handed) | 3d10 |
| Machete / large blade | 3d10 |
| Bow / crossbow | 3d10 |
| Polearm / two-handed blade | 4d10 |
| Handgun | 5d10 |
| Submachine gun | 6d10 |
| Rifle | 7d10 |

| Heavy/anti-materiel weapon | 10d10 |
