Case Study

One Page, One Question

Twenty-three quick-reference sheets for 20 Below, built as job aids. Each one answers a single question a player or GM asks in the middle of play. Each was drawn from real design data rather than from memory, and each is kept in step with the rules as they change. Building them turned out to test the rules too.

The Problem

The rulebook teaches. At the table, nobody wants teaching; they want an answer, now, while four other people wait. I'd already decided to separate the material people learn from the material they look things up in (that's A Rulebook You Read vs. a Rulebook You Reach For). This study is about the lookup material itself: a set of reference sheets, one topic each.

A set like that fails in three quiet ways. It has gaps nobody notices until the moment someone needs the missing sheet. It rounds a number off until it's no longer true. And it drifts: the rules change, and the sheet a player trusts still shows the old rule.

Analysis: When Someone Reaches for a Sheet

A new player

How does this game work, in seven steps?

A player on their turn

What do I roll, and what does it take to hit?

The GM, mid-fight

Who rolls what for this creature, and which number on its card?

The GM, planning

How hard is this, how long does it take, what does this hazard do?

Those moments set the rules for every sheet.

Design Decisions

Audit the set before adding to it

Before drawing anything new, the set was audited for gaps. The first it found: nothing explained how an attack is actually made, meaning how the Element is picked, the three Defenses, and where the damage dice come from. Making an Attack was built to fill it. The same day, Stat Blocks gave the GM's side its own sheet: who rolls what, and which number on a creature's card it uses.

The numbers come first

A reference sheet that rounds a number until it's wrong is worse than no sheet. So each sheet started from design data. For Advantage and Disadvantage, that meant the exact odds computed from every possible roll. The book teaches a simplified version: three curves of the same shape, slid along the dice. The finished sheet keeps that clarity for reading at the table, and puts the exact chances where a player actually uses them, at targets 8, 11 and 14.

Drawing a sheet tests the rule

The most useful thing the sheets did was expose problems in the rules. A job aid can't be vaguer than the rule it shows, so every place the rule was vague, missing or out of date surfaced the moment it had to fit in a box on a page.

One place for the whole set

The sheets live on the GM References page, grouped by topic: The Basics, Characters, Combat, Running Creatures and The World. Any sheet opens in a viewer on the page, and the arrow keys step through the rest in order, so the set reads as one tool rather than twenty-three downloads. I also decided the set is for the website, not print. Hole-punch margins, page order and a test print only matter if we ever print it, so they wait until then.

Kept true

A reference that drifts from the rules teaches the wrong rule with full confidence. So a rules change isn't done until the sheets that show it agree. When the bestiary changed how creatures attack, Stat Blocks followed. When the movement chapter redrew the range bands, Range & Movement, The Round and the desktop app's quick reference followed.

How the Work Ran

  • Checked as drawn. A new sheet was checked against the rules file as it was drawn, which is how the four problems above surfaced. The project's consistency checks run on every rules change.
  • Reviewed by communications. Hillary McKey reviewed the sheets' design, the same review the rest of the project's visuals get.
  • Scope logged as it grew. New sheets, and the rules fixes the sheets turned up, went onto a running list with the date and where each one came from, instead of derailing the sheet in progress.

How the sheets look is covered in the Visual Information portfolio. This study is about what they're for.

Outcome

Twenty-three sheets, each answering one question, in one place, and agreeing with the rules they show. The gap the audit found was filled. The numbers behind the sheets come from computed data, and where a player decides with a number, as on Advantage and Disadvantage, it's the exact one. And four problems were fixed in the rules themselves because a sheet couldn't be drawn around them.

What this study doesn't have yet is evidence from use. The next step is a timed lookup test: the same five questions answered from the web book and from the sheets, by a new player and by an experienced one. Alongside that, playtesters' notes on which sheets actually get reached for.
