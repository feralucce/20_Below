Visual Information Portfolio

A rule you have to read twice is a rule that stops the table. Most of what I've designed for 20 Below, a tabletop RPG I've built over the past year, is an attempt to get a rule off the page and into someone's head in one look. That includes print-ready reference sheets, diagrams built into the rulebook, and maps of systems that were never drawn before.

Reference Sheets

Thirteen sheets, one topic each, all built on the same template: the same header lockup, numbered sections read top to bottom, and the five Element colors meaning the same thing on every page they appear. Once you've learned to read one sheet, you can read all of them. Each is letter-size and rendered at 600 dpi, so it works as a printed handout at the table and as a screen reference.

Design Data

The sheets are for the table. These came first. They're the working diagrams the system was designed and built from: the probabilities, the order of operations, the numbers the apps had to agree with, drawn plainly enough to check. There are twenty-two of them, and they still sit in the rulebook where the prose stops working. Each one is a single SVG in the site's own colors, with written alt text so the rule survives for readers who can't see the picture.

From Source to Finished Piece

Same information, two jobs. The design data had to be right. The finished piece has to be read across a table, mid-fight, by someone who has never seen the rulebook. That means the same numbered panels, the same colors doing the same work as every other reference sheet, and the rule written out in full where the source only had to hint at it. Each one is chosen case by case as the book is prepared for print.

Advantage & Disadvantage

This one took three steps, because the first honest answer wasn't the clearest one. The exact odds, computed from every possible roll, come out as two charts and 114 values, and they're true: Advantage and Disadvantage don't just slide the curve, they narrow it and tip it to one side. But as a visual presentation, the full data set isn't always clear to the average reader, and what a player needs from it is one idea: an extra die moves your odds about two and a half points. So the book's version draws that idea and nothing else, keeping the centres exact and letting the shapes simplify. The finished sheet keeps those same simple curves, on purpose: visual information has to be easy to read first, and it doesn't have to carry every decimal to be right about what matters. The exact numbers still come through where a player uses them, as the chance to succeed.
