Known, unresolved divergence: scriv2web.py and scriv2brew.py format the same manuscript source differently in places — the current example is Gift lists, which the web edition renders as bullet points while The Brewery prints them as run-in prose. Both may be intentional (print density vs. web scanability), but the two outputs have not been reconciled or documented as a deliberate choice yet.
