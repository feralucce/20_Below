Changelog

Newest entries first. Starts 2026-08-20 - not backdated to earlier development history.

Rules

  • 8-21-2026 2100 Added Everyman Gear Packages: 18 free, no-roll starter kits (3 per creation-Wealth Level, 0-5) as an alternative to Wealth Check shopping, access cumulative downward. New Flaw, Destitute, zeroes creation-Wealth and unlocks the exclusive Level 0 tier.
  • 8-21-2026 1200 Clarified Jack of all Trades: unspent Skills Pool points under Tier 1's Trained cap don't convert into points for anything else.
  • 8-20-2026 1445 Every entry in the Adversary Index (Mundane Beasts + Beast Variants), Cryptids, and Nightmare Creatures now has a real 3-5 sentence description covering appearance, behavior, and what makes it distinct at the table, instead of a single one-line flavor hook.
  • 8-20-2026 1340 Reformatted Resources: each of the 23 Resources now gets its own Level table instead of being crammed 2-4 to a table, plus a jump list to navigate straight to one. No mechanical changes - table layout only.
  • 8-20-2026 1251 New Creation-Wealth Reference doc, spelling out the gear-shopping procedure at character creation step by step, with a flowchart diagram. Closes the second of two "new reference docs" flagged since RP-10 - Advancement Reference was the first.
  • 8-20-2026 1209 Balance-tested Bow dice ratings against the Soak math, split into three tiers: Recurve bow raised to 5 (Handgun-tier), new Compound bow entry at 7 (Rifle-tier), Crossbow raised to 7 to match, new English longbow entry at 10 (Heavy-tier). Closes the last of weapons.md's four tracked sub-gaps.
  • 8-20-2026 1147 Added an Ammo Recovery rule for Bow and Thrown weapons: recover half the ammo spent (rounded down) if you control the battlefield after a fight, unlike firearm cartridges which aren't reusable.
  • 8-20-2026 1130 Added reload rules, a longstanding gap: a new Reload Combat Action, with cost varying by how the weapon actually loads (magazine/speed-loader/chain-fed and crossbow take one action, a tube-fed shotgun takes a Slow action, a quiver-drawn bow reloads free). New Reload column on weapons.md's Basic Weapons table.
  • 8-20-2026 1020 Built out the Scars mechanic fully: Poise now goes negative (new Humiliated status, no death threshold), Mental Scars finally defined (was flagged as TBD), Battle Scars now accumulate and can be healed away after a Month by Healing/Regeneration. New Flaw: Shaken Confidence. New docs/scars.html with 27 Physical, 23 Mental, and 15 Social scar flavor options.
  • 8-20-2026 0927 Added 9 new Boons (Animal Rapport, Compact Frame, Iron Grip, Lie Detector, Never Winded, Quick Study, Restful Trance, Unshakeable Alibi, Weathered). Also newly defined Short Rest/Full Night's Rest duration and frequency, a real rules gap Restful Trance surfaced.
  • 8-20-2026 0841 Added 3 new Flaws: Item of Power (a Gift depends on an external item), Ritual Required (a Gift needs preparation time), Incantations (a Gift needs a spoken trigger).
  • 8-20-2026 0830 Added 14 new Resources (Safehouse Network, Underworld Reputation, Medical Access, Legal Counsel, Media Contact, Black Market Access, Spiritual Standing, Corporate Backing, Informant Network, Signature Possession, Sanctuary Standing, Guild Standing, Debts Owed, Territory), full 5-level tables for each.
  • 8-20-2026 0817 Resource creation cost halved: 1 point per level instead of 2 (pool stays 6 points, now buys 6 levels of Resources total instead of 3).
  • 8-20-2026 0812 Created changelog. Added 6 Gifts (Necromancy, Drone Swarm, Berserker, Conjured Armory, Memory Manipulation, Forcefield) and 1 Boon (Always Connected). Defined Milestone Award, the Combat Actions list, and Limiter buy-off costs. Various fixes and cleanup.

App

  • 8-21-2026 2201 Character creation step order updated: Boons and Flaws now come right after Descriptors, ahead of Skills/Resources/Gifts. New version indicator under the Character Creator header (desktop only) - green "Up to date" or a flickering red "Needs updating," checked against the latest release on load. Everyman Gear Packages is now a real picker in the Equipment step, not just rules text. Desktop v0.8.0.
  • 8-21-2026 1735 Fixed a real, longstanding desktop bug: Import character has been broken since the fs-plugin permission cleanup on 2026-08-20 - every real Import attempt failed on a permission error, shown misleadingly as "not a valid character file." Now reads the file the same ACL-bypass way Save/Load already do. Desktop v0.7.4.
  • 8-21-2026 1700 Desktop v0.7.3 released, carrying the fix below plus the Jack of all Trades Skills Pool fix and the app's own header now showing its version live.
  • 8-21-2026 1655 Fixed a real bug: loading a character saved before a Resources (or similar) rules update could silently break its pool math (showing as blank/broken instead of a number). Importing, loading, and the auto-saved draft now all fill in any newly-added catalog entries with defaults instead of dropping them.
  • 8-21-2026 1200 The Skills Pool now locks at 0 the moment Jack of all Trades Tier 1 is bought, matching the new rules clarification - Tier 2 is unaffected.
  • 8-20-2026 1039 Fixed the character sheet's Poise track to match the new negative-Poise rule (Humiliated status, correct below-0 rest recovery cap). Wired up the Limiter buy-off control on the Advancement tab. Fixed the Gift Adder "Buy" button to charge the correct Advancement XP rate instead of the creation-time cost.
  • 8-20-2026 0812 Applied site-wide brand color theming. Rebuilt the Dice Roller. Fixed Import, Load, and Export functions.
