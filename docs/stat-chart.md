# Stat Chart (Reference Snapshot)

A quick-reference summary of the current Attribute/sub-stat state. **This is a snapshot, not the source of truth** — if it ever conflicts with [rules/core-mechanic.md](../rules/core-mechanic.md) or [rules/fate.md](../rules/fate.md), those win. Update this file whenever the underlying mechanics change.

## Separate Pools/Resources (not sub-stats)

- **Ki** — average of all five combat sub-stats (Soak, Initiative, Ferocity, Stamina, Warp), doubled. Target number for the Fatigue Check; depletes on failure (refill trigger TBD); can also be spent directly — 1 Ki preserves 1 Health Level, 1 Ki per die for [Ki Infusion](../rules/core-mechanic.md#ki-infusion) on **any** attack type (Physical/Social/Mental, unified 2026-08-10), or 1 Ki per step to [Bump Action Band](../rules/combat.md#action-bands).
- **Fate Tokens** — the earn/spend currency. Gained via Nature, voluntary Disadvantage, Flaws, daily regen, Milestones, GM discretion. Spent on Kotodama (formerly separate Push the Fiction/Narrative Control, merged and renamed 2026-08-10), plus two flagged/under-review options (Automatic Success, Boost a Check). **Bump Action Band and Fate Token Infusion both moved to direct Ki spends, 2026-08-10** — Kotodama is now the only Fate Token spend with a live cost.

## Still Undefined

Potence's Carrying Capacity/Break Threshold scaling, Stamina's non-combat mechanic, Ki's refill trigger, [weapons.md](../rules/weapons.md)'s dice ratings (unbalanced first draft), Kotodama's Plausibility token costs and pooled Magnitude tiers, and the rest of the open-questions TODO list in [design-log.md](design-log.md#open-questions). **Health Level recovery, Battle Scars, what a connecting Social/Mental die costs the defender, and objects' resistance to Potence (reusing Soak, not a separate Hardness stat) are all resolved** - see [core-mechanic.md](../rules/core-mechanic.md#health-level-recovery), [#poise](../rules/core-mechanic.md#poise), [#sanity](../rules/core-mechanic.md#sanity), and [#potence](../rules/core-mechanic.md#potence).
